## 🌌 Overview

This repository houses the source code for my interactive 3D developer portfolio. Built without bloated heavy front-end frameworks, the site emphasizes **raw performance, 60fps WebGL rendering, architectural minimalism, and cinematic storytelling**.

Visitors embark on a seamless celestial trajectory traversing projects, technical competencies, and academic evolution.

---

## ✨ Key Features & Architecture

### 1. 🪐 WebGL & Three.js Celestial Space Engine
* **Interactive Starfield & Nebula Particles**: Multi-layer dynamic particle system responsive to cursor coordinate parallax and scroll velocity.
* **Camera Choreography**: Smooth orbital perspective panning synchronized with page sections.
* **Resource Optimization**: Custom render loops with frame-budget throttles and adaptive pixel ratio scaling.

### 2. ⚡ Cinematic Scrollytelling
* **Lenis Smooth Scroll Engine**: Modern kinetic scroll physics with momentum dampening.
* **GSAP ScrollTrigger**: Pinned timeline controllers orchestrating layout transforms, 3D card tilts, and camera focal points.
* **Proximity Interpolation**: Dynamic card depth-of-field scaling, opacity falloff, and subtle 3D rotational perspective as cards glide through viewport center.

### 3. 🛸 Pinned Section Highlights
* **Hero Mission Control**: Sci-fi telemetry HUD displaying live velocity, altitude, audio state, and dynamic magnetic cursor.
* **Featured Works Deck**: Pinned interactive project showcase featuring live production builds, GitHub source links, and tag telemetry.
* **Orbital Competencies**: Solar-system-inspired technical proficiency map organized by planetary orbital rings.
* **Horizontal Chronology Deck**: Minimalist horizontal station cards documenting educational milestones and 3rd-year undergraduate AI specialization at Jain University.
* **Frameless Contact Hub**: Streamlined direct communication portal with single-click email clipboard copy and PDF resume download.

## 🚀 Quick Start & Local Development

This portfolio is built with zero compile-step dependencies, making it blazing fast to run locally.

### Prerequisites
You only need a modern web browser and a lightweight local HTTP server (such as Python, Node `serve`, or VS Code Live Server).

### 1. Clone the repository
```bash
git clone https://github.com/juug24btech22417-del/portfolio.git
cd portfolio
```

### 2. Start a local server

**Using Node.js (`npx`):**
```bash
npx serve .
# or: npx live-server
```

**Using Python 3:**
```bash
python -m http.server 4321
```

### 3. Open in Browser
Navigate to `http://localhost:4321` (or the port specified by your local server).
